# Editorial Split Rail

Direction 05 is a restrained editorial folio. A narrow rail of square image crops controls a native horizontal scroll-snap sequence; each spread keeps the supplied project image on the left and only the project name, short description, collaborators, and optional link on the right. The vertical rail becomes a horizontal strip on smaller screens.

Project changes recompose solid paper, ink, and accent planes behind a fixed typographic baseline grid. There are no decorative gradients: the project palette behaves like a new printed sheet, and the content remains the visual priority. Georgia and the existing system sans stack provide structural contrast without adding a font payload.

## Interaction coverage

- Click a square crop, or use Arrow keys, Home, and End from either the rail or carousel.
- Trackpad and touch use native mandatory horizontal snapping with active-tab synchronization.
- All controls meet the 44px minimum, use roving tab focus, and provide strong focus-visible states.
- Reduced motion removes background travel, copy drift, smooth scrolling, and skeleton shimmer.
- Ready, loading/skeleton, and empty states preserve the image geometry and hierarchy.
