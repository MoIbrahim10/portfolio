# Chromatic Filmstrip

A minimal horizontal project reel that combines direction 4's native rail, direction 9's cinematic focus, and direction 10's compact index controls without reproducing any of them. Each project remains a complete semantic article, pairing a fixed-ratio image with only its name, summary, collaborators, and optional link.

## Interaction

- Square image tabs use roving focus and `ArrowLeft`, `ArrowRight`, `Home`, and `End`.
- Touch, trackpad, and wheel input use native horizontal scrolling with mandatory snap points.
- The nearest panel updates the active tab, palette, progress, and film counter after scrolling.
- Pointer changes use a short directional projected-film wipe; keyboard and reduced-motion changes are instant.
- Ready, loading/skeleton, and empty states share the same restrained film language.
