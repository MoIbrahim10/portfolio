# Dimensional Slide Stack

A native horizontal snap gallery where the active project occupies a crisp image-left, details-right architectural plane. Adjacent projects remain visible as shallow offset slabs, while square image tabs act as tactile depth chips. Project changes retarget the slab depth, edge light, palette, and background horizon without letting decoration outrank the work.

- **Name:** `ui-animation`
- **URL:** https://www.skills.sh/mblode/agent-skills/ui-animation

Its decision framework shaped purposeful orientation/continuity motion, compositor-only transitions, immediate keyboard navigation, and the reduced-motion path.

## Interaction model

- Native horizontal scroll snapping supports touch and trackpads.
- Six square image tabs select projects and expose full accessible names.
- Arrow Left/Right, Home, and End operate both the roving tab set and focused carousel.
- Scroll position synchronizes the active chip, palette, depth planes, counter, and progress.
- Every slide contains only project name, description, collaborators, and optional project link.
- Ready, loading, and empty states preserve stable geometry at desktop and mobile sizes.
