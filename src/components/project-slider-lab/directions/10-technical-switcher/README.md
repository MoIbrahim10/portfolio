# Technical Switcher

A compact instrument-panel interpretation of the requested project slider. Six image-only square tabs control a strict left-image/right-copy snap rail; native horizontal scrolling keeps touch and trackpad input direct, while the counter, grid progress, palette, and pixel scan resolve around the active project.

## Interaction

- Click or tap any 44px image cell to select its project.
- Use Arrow Left/Right, Home, or End from the tab row or slider viewport.
- Swipe or scroll horizontally; the nearest snapped article synchronizes the selected cell and background.
- Keyboard and reduced-motion changes are instant. Pointer changes use short orientation and continuity transitions.
- Ready, loading/skeleton, and empty states are included.
