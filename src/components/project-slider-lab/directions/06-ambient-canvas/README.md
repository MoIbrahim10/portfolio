# Ambient Canvas

Direction 06 keeps the project itself dominant: a fixed-ratio image sits left of only the project name, short description, collaborators, and optional link. Small square image windows select the six shared projects and mirror the active slide while native horizontal scrolling supplies touch and trackpad snap behavior.

The backdrop responds to each project palette through a soft color cloud, restrained solar disc, and low stepped horizon. Pointer and scroll changes crossfade and gently settle the field for continuity; keyboard navigation is intentionally instant, and reduced-motion mode removes transitions.

## Interaction coverage

- Select a square image window by click or touch.
- Use ArrowLeft, ArrowRight, Home, or End on the selector or focused carousel.
- Scroll or swipe horizontally with mandatory native snap points and active-state synchronization.
- All selectors meet the 44px target minimum and expose strong focus-visible states.
- Ready, loading/skeleton, empty, and reduced-motion states preserve media geometry.
