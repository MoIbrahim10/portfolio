# Solar Aperture

An image-first, left-media/right-copy horizontal snap slider. Six square project-image tabs trace a shallow orbit around a restrained solar aperture; selecting or scrolling projects reveals the next palette radially from the active tab.

## Skill

- **Name:** `ui-animation`
- **URL:** https://www.skills.sh/mblode/agent-skills/ui-animation
- **Use:** Searched on skills.sh before design. The skill was already installed in the shared workspace, so no additional skill was installed. It guided instant keyboard navigation, interruptible pointer/scroll movement, the radial `clip-path` reveal, and reduced-motion behavior.

## Interaction model

- Native horizontal scroll snapping for touch and trackpads.
- Image-only tabs select a project and expose its name accessibly.
- Arrow Left/Right, Home, and End navigate the roving tab set.
- Scrolling continuously synchronizes the active tab, palette, counter, and progress.
- Ready, loading, and empty states use stable fixed-ratio geometry.
