# Refined project slider contract

Every direction receives the same six projects from `projects.ts` and the same supplied placeholder image. The old project laboratory remains untouched.

Required in every direction:

- square image tabs with useful accessible names and 44px targets
- horizontal scroll snapping plus click, keyboard, and touch navigation
- media on the left and minimal name, description, link, and collaboration on the right
- project-reactive background or transition motion using the existing `motion` package
- ready, loading, and empty states; fixed media dimensions; reduced-motion support
- one isolated `index.tsx`, `styles.module.css`, and `README.md` with the skills.sh record
