# Direction 01 — Editorial Grid

An asymmetric magazine system: the featured project behaves like a cover story, while the other five projects form an uneven editorial sequence with portrait, split, square, and landscape modules. The design keeps imagery and project information dominant, using the navy, gold, and red identity as rules, folios, and stepped media edges.
