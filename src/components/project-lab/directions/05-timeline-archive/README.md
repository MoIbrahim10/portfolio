# Direction 05 — Timeline Archive

A current-to-past career continuum rather than a card feed. A navigable year rail opens the archive, the current project occupies a wide present-tense feature, and five earlier records alternate media and details across one uninterrupted chronological datum. Gold year points, a restrained red current marker, stepped media cuts, and navy ledger rules reinterpret the existing identity while project imagery remains dominant.
