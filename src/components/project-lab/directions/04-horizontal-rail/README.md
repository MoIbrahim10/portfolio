# Direction 04 — Processional Rail

A cinematic-width, scroll-snapped route treats each project as a chapter in one
continuous exhibition. The featured first stop opens into the widest frame;
supporting stops tighten into a measured cadence connected by an indexed path.
Native horizontal overflow preserves touch/trackpad behavior and leaves vertical
page scrolling untouched. Previous/next controls plus Left, Right, Home, and End
keys provide explicit keyboard navigation.
