# Project presentation laboratory

Ten isolated project-display systems share `shared/projects.ts`, the same six SVG previews, `ProjectMedia`, and the selected V2 Cut Corner control. The existing brand assets, logo component, favicon, button laboratory, and home route were not rewritten by this laboratory.

1. Editorial Grid — [high-end-visual-design](https://www.skills.sh/leonxlnx/taste-skill/high-end-visual-design)
2. Museum Catalog — [frontend-design](https://www.skills.sh/block/agent-skills/frontend-design)
3. Split-Screen Register — [interaction-design](https://www.skills.sh/wshobson/agents/interaction-design)
4. Processional Rail — [web-design-guidelines](https://www.skills.sh/vercel-labs/agent-skills/web-design-guidelines)

7. Project Dossier — [make-interfaces-feel-better](https://www.skills.sh/jakubkrehel/make-interfaces-feel-better)

Each direction folder contains the exact install command and state/accessibility coverage. All ten passed the structural review for the comparison lab; no finalist is selected or integrated.

## Shared content note

The repository did not contain project data or project imagery before this task. The laboratory therefore uses one new, isolated six-project evaluation dataset under `shared/` and `public/projects/`; no existing content or asset was changed.
