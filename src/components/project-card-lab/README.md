# Project card laboratory

Ten isolated implementations compare the same six projects and the same
placeholder image. Closed cards are image-only, the canvas remains neutral, and
project details appear only after activation. No direction has been selected
for portfolio integration.

## Shared behavior

- native horizontal scroll snap, touch and keyboard navigation
- accessible modal detail surface with Escape and focus restoration
- project name, summary, gallery, collaborators, and optional project link
- ready, loading, empty, responsive, and reduced-motion states
- fixed-ratio media with intrinsic dimensions and lazy loading
- existing Motion React and V2 Cut Corner buttons; no new runtime dependency
