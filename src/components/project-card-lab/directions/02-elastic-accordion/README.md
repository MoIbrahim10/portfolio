# 02 — Elastic Accordion

The rail keeps project cards visually image-only, then gently redistributes
horizontal space toward the current hover, focus, or selected card. Activation
opens a restrained bottom sheet with description, collaborators, gallery, and
project link.

## Motion

- Motion layout spring for interruptible rail reweighting
- critically damped transform spring for sheet entry and exit
- instant arrow-key navigation and instant reduced-motion fallback
- fine-pointer-only hover lift

## Skill

- **ui-animation**
- https://www.skills.sh/mblode/agent-skills/ui-animation

The skill was found through skills.sh and was already installed in the shared
workspace, so no dependency or skill-folder changes were needed.
