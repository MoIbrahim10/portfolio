## Interaction

Six image-led projects share one native, mandatory-snap horizontal conveyor. A thin six-color gate and paper underlay provide the prism moment without changing the canvas. Pointer hover, focus, scrolling, and arrow/Home/End navigation update the compact external project index. Clicking, tapping, Enter, or Space opens a responsive project drawer.

## Accessibility and resilience

The implementation uses semantic landmarks, sections, articles, headings, intrinsic lazy-loaded media, descriptive alt text, 44px controls, visible focus, a trapped modal focus path, Escape dismissal, focus restoration, background inertness, reduced-motion behavior, fixed-ratio loading frames, image-error fallbacks, and a quiet empty state. Optional gallery, collaborator, live, and repository content is rendered only when supplied by the shared dataset.
