## Interaction

Six project sheets descend through a quiet vertical drafting datum in a stepped plan. Each image is the project trigger; opening one unfolds a full-width detail layer directly inside the page rather than using a horizontal rail or side/bottom drawer. The selected plan includes the unchanged description, a fixed-ratio gallery when supplied, collaborators when supplied, and only the links present in shared data.

## Motion

Jakub Krehel's production-polish lens is primary and Jhey Tompkins's spatial-experiment lens is secondary. Motion only clarifies sheet arrival, hover feedback, and inline plan continuity; it uses transform and opacity with restrained custom easing. Keyboard-initiated transitions and reduced-motion preferences are instant.

## Accessibility and resilience

The page uses semantic landmarks, sequential headings, native project buttons, `aria-expanded`/`aria-controls`, Enter/Space activation, Escape close, focus restoration, natural arrow/Home/End movement, intrinsic lazy-loaded images, 44px controls, visible focus, fixed media ratios, quiet static skeletons, an empty project sheet, and image-error fallbacks. Optional galleries, collaborators, live links, and repository links render only when supplied by the shared dataset.
